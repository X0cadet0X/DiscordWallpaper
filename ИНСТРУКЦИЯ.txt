===========================================
  Discord Wallpaper v2.0.0 by X0cadet0X
===========================================

ОПИСАНИЕ
--------
Плагин для BetterDiscord, который добавляет маленькую кнопку (🖼)
в правом нижнем углу Discord. Позволяет установить свой фон —
картинку, GIF или видео — с тремя слотами для сохранения
и кнопкой возврата к стандартному виду одним нажатием.


ТРЕБОВАНИЯ
----------
- Windows 7 / 10 / 11
- Discord (стабильная версия) — https://discord.com
- BetterDiscord v1.9.0+ — https://betterdiscord.app


УСТАНОВКА
---------
1. Установи BetterDiscord с сайта https://betterdiscord.app
   После установки запусти Discord один раз.

2. Положи все файлы в одну папку:
     DiscordWallpaper.plugin.js
     install.vbs
     uninstall.vbs

3. Дважды кликни install.vbs
   Появится сообщение об успешной установке, чёрного окна не будет.

4. Открой Discord:
   Настройки → BetterDiscord → Plugins → включи Discord Wallpaper

5. Кнопка 🖼 появится в правом нижнем углу Discord.


КАК ПОЛЬЗОВАТЬСЯ
----------------
• Нажми 🖼 чтобы открыть панель.
• Нажми "Загрузить 1 / 2 / 3" чтобы добавить фон в слот.
• Нажми на миниатюру слота чтобы применить этот фон.
• Ползунок "Затемнение" (0–100%) регулирует прозрачность интерфейса.
• Нажми "Вернуть исходный фон" чтобы убрать фон.
• Нажми EN/RU в правом верхнем углу панели чтобы сменить язык.

Поддерживаемые форматы:
  Картинки : PNG, JPG, WEBP (автоматически уменьшаются до 1920px)
  GIF       : анимированные фоны (до 20 МБ)
  Видео     : MP4, WebM — автовоспроизведение, зацикленно,
              без звука (до 20 МБ)
  Совет     : для видео лучше использовать короткие клипы 5–15 секунд.


УДАЛЕНИЕ
--------
Дважды кликни uninstall.vbs — плагин и сохранённые данные
будут удалены. Discord вернётся к стандартному виду после перезапуска.

Или вручную:
  Удали DiscordWallpaper.plugin.js из папки:
  %APPDATA%\BetterDiscord\plugins\


РЕШЕНИЕ ПРОБЛЕМ
---------------
Плагин не загружается?
  → Убедись что файл называется точно: DiscordWallpaper.plugin.js
  → Выключи и включи плагин в настройках BetterDiscord.

Фон не появляется?
  → Попробуй выключить и включить плагин.
  → Проверь что размер файла не превышает 20 МБ.

Кнопка 🖼 пропала?
  → Полностью перезапусти Discord
    (правый клик на значке в трее → Выйти из Discord).

BetterDiscord сбросился после обновления Discord?
  → Переустанови BetterDiscord — плагин и слоты сохранятся.

install.vbs пишет "BetterDiscord не найден"?
  → Сначала установи BetterDiscord, запусти Discord один раз,
    потом запусти install.vbs снова.


ПРИМЕЧАНИЯ
----------
• Модификация клиента Discord технически нарушает правила сервиса.
  Визуальные плагины вроде этого крайне редко приводят к блокировке,
  но ты используешь его на свой страх и риск.
• Картинки, GIF и видео хранятся локально в папке BetterDiscord.
  Никакие данные не отправляются в интернет.
• Все настройки сохраняются между перезапусками Discord.
